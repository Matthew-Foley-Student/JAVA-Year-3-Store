# AI Toy Store Database

CST-339 Programming in Java III

Database Developer: Dominick Spegnolo

## Database Technology
- MySQL Server 8.0.46
- MySQL Workbench
- Spring Data JPA (planned integration)

## Database Tables
1. users
2. categories
3. products
4. inventory
5. shopping_carts
6. cart_items
7. orders
8. order_items

## Description
This database supports the AI Toy Online Retail Store,
including product management, inventory tracking,
customer accounts, shopping carts, and order processing.

The database uses primary and foreign keys to
maintain relationships between records.
